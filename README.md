# Water Report API

Plataforma digital para el reporte ciudadano de infraestructura y fugas de agua potable. Desarrollado con Django REST Framework y contenedorizado con Docker.

##  Tecnologias utilizadas
* **Backend:** Python 3.12 / Django 6.0 / Django REST Framework
* **Entorno de desarrollo:** WSL (Ubuntu 24.04)
* **Contenedorización:** Docker & Docker Compose

##  Como ejecutar el proyecto localmente

### Prerrequisitos
Tener instalado [Docker](https://www.docker.com/) y Docker Compose en tu sistema.

### Pasos para iniciar

1. Clona este repositorio en tu maquuina local:
   git clone <https://github.com/Turbo307/water.git>
   cd water
